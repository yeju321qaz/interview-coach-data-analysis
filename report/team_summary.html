02 · 실험 결과

STT 실험 결과

무료 로컬 음성인식 모델 Whisper tiny로 음성 12개, 약 14.47분을 전사했습니다. 같은 모델의 두 설정을 비교했습니다.

시험 설정문자 오류 비율(CER)전체 처리시간
설정 121.12%약 82초
설정 214.30%약 137초

이번 표본에서는 설정 2의 오류 비율이 낮고 시간이 더 걸렸습니다. ‘어·음’ 같은 추임새가 빠질 수 있어 유창성 분석에는 추가 확인이 필요합니다.

CER는 기준 전사와 비교한 문자 단위 오류 비율입니다. 사람이 검수하지 않은 AI Hub 전사 기준의 임시 결과이며, 실제 서비스의 정확도나 실시간 반응속도를 검증한 것은 아닙니다. Google·Azure 음성인식 비교는 아직 계획 단계입니다.

03 · 구현·검증

구현 및 검증 방식

처리 흐름

면접 음성 → 글로 변환 → 질문의 핵심과 답변 비교 → 이탈이 지속되면 알림 → 답변 종료 후 구조·유창성 리포트

현재는 질문과 답변의 단어 관계를 비교하는 간단한 기준선과, 판단이 불확실하면 알림을 보류하는 규칙을 시험했습니다. 실제 이탈을 정확히 잡는지는 아직 검증하지 않았습니다.

질문과 다른 답변을 구분한 기존 수치를 실시간 이탈 감지 정확도로 쓰지 않습니다. STAR도 키워드로 살핀 탐색 결과이며, 사람이 확인한 답변 완성률은 아닙니다. 알림을 언제 띄울지도 검증 전 설계안입니다.

04 · 수집 계획

추가 데이터 수집 계획

기존 데이터에는 언제 질문에서 벗어났고, 돌아왔으며, 언제 알림이 필요한지에 대한 정답이 없습니다.

녹음 유형계획
질문에 맞게 답하는 경우20건
다른 주제로 계속 벗어나는 경우20건
잠깐 벗어났다가 돌아오는 경우20건
경험 답변에서 STAR 요소를 빠뜨린 경우20건

총 20명 × 4유형 = 80건을 계획했습니다. 두 사람이 이탈·복귀·알림 시점과 STAR 근거를 표시하고, 의견이 다르면 다시 판정합니다. 개발·검증·최종 평가에 같은 사람이나 의미가 같은 질문이 섞이지 않도록 나눕니다.

실제 녹음은 아직 0건입니다. 연기한 이탈과 자연스럽게 생긴 이탈을 구분합니다. 최종 평가 표본은 유형별 8건이라 큰 성능 결론을 내리기에는 작습니다. 연습 후 성장은 별도 전후 녹음이 필요합니다.
