# 한글 표시 오류 수정

공개 URL에서 실제로 한글이 깨지는 문제를 재현했다. CSS 색상은 밝은/어두운 모드 모두 정상 대비였으나 UTF-8 선언 없는 HTML 조각을 배포해 브라우저가 한글 인코딩을 잘못 해석했다. 앞선 로컬 파일 확인만으로 공개 표시를 충분히 검증하지 못했다.

HTML5 doctype, html lang=ko, head, 앞부분 meta charset=utf-8, 모바일 viewport, body를 명시했다. 기존 내용·수치·그래프·디자인 색상은 유지했다. 공개용 사본 생성과 HTML 재생성 과정에도 같은 처리를 적용했다.

공개 버전 3 배포 후 실제 URL에서 밝은/어두운 모드 × 데스크톱/모바일 4조건을 확인했다. document.characterSet=UTF-8, 정상 한글 제목/본문, 깨진 문자 없음, 기존 SVG 4개, 모바일 폭 390px, JavaScript 오류 없음으로 통과했다. 결과는 live_fixed_checks.json과 화면 PNG에 있다.
