## 발표용 배치

앞쪽: **통합 현황 → 데이터 확보 → 품질·재현 검증 → 실제 tiny STT 시험 → 신규 80건 수집 계획 → 해석 수정 기록**.

아래쪽: 질문 짝 기준선·구현 가설, 기존 분석 요약, 분포·유창성·STAR·침묵·질문 유형 그래프와 상세 통계, 평가 한계, 이전 단계 부록. 그래프와 상세 통계는 삭제하지 않았다.

## 수정 파일

- `report/index.html`: 발표 핵심 순서·요약·기존 AUC/STAR/설계 가설 표현.
- `report/integrated_standalone.html`: 전달용 단일 HTML에도 같은 해석 적용.
- `report/verification.html`, `report/phase2.html`: 이전 단계 문구에도 오프라인 과제·미검수·당시 상태를 명시.
- `public_interview_report/dist/index.html`: 공개용 사본 갱신. 원문 음성·CSV·모델은 미포함.
- `refine_report_for_presentation.py`: 재현 가능한 편집 단계. 실험은 실행하지 않음.
- `phase3_integrated_20261029/build_web.mjs`: 재생성 후 편집 단계를 자동 적용해 옛 표현으로 돌아가지 않게 함.

48개 사람 검수는 계속 보류, 신규 녹음은 미수집이다. 기존 분석 코드·data·outputs·실제 모델 결과 JSON·CSV는 수정하지 않았다. 공개 URL은 같은 주소를 유지하고 새 버전으로 배포한다.
